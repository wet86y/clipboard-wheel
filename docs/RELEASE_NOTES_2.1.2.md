# 超级中键 2.1.2

本版本改进设置界面和表格文本清洗，并加强全局输入复位与系统托盘恢复。

- 基础设置按轮盘外观、剪贴板功能、启动与权限分组；页面可滚动，保存和关闭按钮固定显示，控件布局和图标也作了调整。
- 表格文本清洗会处理首尾空行和横向空白，并保留正文内部换行。新增默认关闭的“换行清洗”子选项，可将表格纯文本中的换行删除并拼接成一段；该功能不改写表格富文本格式。
- 按 Esc（退出键）或 Windows 键可触发全局输入复位；检测到输入钩子或界面心跳异常时，也会取消轮盘、清理待执行动作并释放程序按下的鼠标和键盘状态。
- Windows 资源管理器重启后，系统托盘图标会自动恢复，并保留程序原有的启用或暂停状态。
- 新增的换行清洗设置在旧配置中默认关闭；需要点击“保存”后生效，关闭父级表格清洗选项时会同步取消并禁用。
